Support

Raffkin is an open-source project, published by the Open Agent and AI Security community and sponsored by Exabeam. It is community supported, as is, under the Apache-2.0 license. There is no service level, no support desk and no warranty; the people who build it answer questions as they can.

Getting help

  • Something isn't working? Run the diagnostics first — they name the missing step: preflight.sh in the installed plugin (claude plugin list or codex plugin list prints its path).
  • Questions and bug reports: open an issue at github.com/open-agent-ai-security/raffkin/issues. Include the host (Claude Code or Codex), the plugin version, and the preflight.sh output.
  • Security vulnerabilities: please do not open a public issue — follow SECURITY.md.

Supported by Exabeam

Exabeam offers a supported SOC Agent pack — the same agentic SOC skills, delivered and supported under Exabeam's commercial terms — through the Exabeam Plug-in Catalog. If you are an Exabeam customer and want a supported build with a support path, that is where it lives.
