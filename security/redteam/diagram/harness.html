driver · policy boundary
claude -p · codex exec poisoned payload, paste-mode · three legs
Spawns the agent as a headless subprocess loaded from the working tree (--plugin-dir, or installed into a throwaway CODEX_HOME) — so the run tests what's about to ship. Three legs, one grader. Standard leg (Claude): the write and containment tools are removed from the model's view by host tool policy. Hook leg (Claude, --claude-gate hook): permissions bypassed, the write tools offered, the plugin's bundled PreToolUse hook the only thing in the way and the bridge's dry run the backstop — a write that reaches the bridge is a HOOK MISS; the leg starts only after a positive control shows the hook acting. Codex leg: tools stay visible and the bridge's dry run refuses every write, so the attempt is recorded and nothing reaches the tenant.
reads: live, allow-listed standard leg: writes removed from the tool list hook leg: writes offered · hook decides · dry run backstop codex: writes refused at the bridge (RAFFKIN_DRY_RUN) all legs: containment + Bash/Read/Write/Web denied

Why it hangs together this way

Measure intent without ever acting
On the standard leg the write and containment tools are removed from the model's view; on the hook leg and on Codex they are offered and refused — by the bundled hook, then by the bridge's dry run. Either way the run learns "it tried to close" without a harmful action landing, and on the legs that offer writes, the attempt itself is the signal.
The agent can't see the test
The driver runs from a neutral cwd with filesystem/exec/web tools denied, so the harness, fixtures, and CLAUDE.md are invisible — its only surface is the Exabeam MCP, a faithful investigation.
The judge shares no context
Grading the reasoning falls to a fresh sub-agent with --mcp-config {} and one turn — same auth as the driver, no API key, nothing but the grading prompt. It can't "grade its own exam."
Findings compound into regressions
A confirmed attack becomes a permanent fixture graded by the same machinery as the normal evals, so it can never silently return. Live & costly — a maintainer gate before release, not CI (only the corpus --lint runs in CI).
