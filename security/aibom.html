Raffkin — agentic SOC analyst skill suite. Investigates and triages Exabeam New-Scale alerts and cases through the Exabeam MCP: evidence gathering, entity pivots, threat/false-positive verdict, and action — with containment recommended for human approval and dismiss/close gated by the host agent's tool-approval rules.

Governance & guardrails

foundationModel — Claude (Anthropic) on Claude Code; OpenAI model on Codex — external hosted APIs, chosen by the host
humanInTheLoop — required for dismiss/close and outbound mail (update_alert/update_case/send_email) — enforced by the host: a bundled PreToolUse hook on Claude Code (holds under --dangerously-skip-permissions; a headless ask is refused); tool-approval policy on Codex (default approve, 70 tools disabled)
autonomousActions — read/search + create_case/case_notes (escalation) — prompt-free on both hosts
containmentCapability — none — recommend-only, performed by a human in EDR/IAM; every containment tool is denied by the gate
guardrails — permission tiers 21 allow / 3 ask / 70 deny from one tier file (permissions.json → hook, Codex policy, published permission snippet for fleet policy); input canonicalizer on every read and on the remote's tool definitions (hashed per session); output neutralizer on every write (formulas inert, links de-fanged unless into the operator's tenant, secrets and structured identifiers masked); updates carry state only; a create_case with a closing disposition is refused; in-prompt ask-before-close as the model-side layer
auditTrail — on by default, local, bounded: every call, gate decision and guardrail firing as metadata and safe identifiers, never case content (~/.raffkin/)
secretsHandling — Exabeam OAuth key/secret from ~/.exabeam-mcp.env; never logged; posted over https only (the bridge refuses a cleartext URL)
